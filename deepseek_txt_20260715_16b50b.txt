## 1. SKILL ACTIVATION (Always Active)

Load and apply ALL document skills from my `.claude/skills/` directory. Prioritize these skills in this order:

  1. `doc-init` - For new documentation projects
  2. `doc-update` - For updating existing docs
  3. `doc-compact` - For optimizing bloated documentation
  4. Any custom document skills in my skills folder

## 2. AGENT DEPLOYMENT

When generating documents, automatically invoke these agents:

  - document-generator: For creating new documents from scratch
  - technical-writer: For technical documentation and API docs
  - doc-updater: For maintaining and updating existing docs
  - copywriter: For marketing, proposals, and business documents
  - api-doc-generator: For API reference documentation

## 3. TEMPLATE ENFORCEMENT

- ALWAYS use the templates from my `.claude/skills/*/templates/` folder
- If no template exists for a specific document type, ask me which format to use
- Apply these formatting rules:
  - Use tables with invisible borders for alignment
  - Apply "Keep with next" for paragraph flow
  - Use "In Line with Text" for all objects
  - Enforce brand colors and fonts from my style guide

## 4. DOCUMENT TYPES & FORMATS

For each request, generate the appropriate format:

  | Document Type      | Output Format | Skill/Agent             |
  | :----------------- | :------------ | :---------------------- |
  | Reports & Proposals| DOCX          | doc-init + copywriter   |
  | Technical Docs     | MD / DOCX     | doc-init + technical-writer |
  | Presentations      | PPTX          | doc-init + document-generator |
  | API References     | MD / HTML     | api-doc-generator       |
  | Business Letters   | DOCX          | copywriter              |
  | Spreadsheets       | XLSX          | document-generator      |

## 5. PPT GENERATION PROTOCOL

For presentations, ALWAYS:

  1. Start with `doc-init` to scaffold the structure
  2. Use `document-generator` agent for slide creation
  3. Apply templates from `.claude/skills/presentation-templates/`
  4. Include:
     - Title slide with branding
     - Agenda/Overview slide
     - Content slides with visuals (suggest images/diagrams)
     - Summary/Conclusion slide
     - Q&A slide
